# [DevOps](https://github.com/andrew-dibov/devops) : Сетевая инфраструктура

Развертывание сети для последующих рабочих нагрузок. VPC с публичными и приватными подсетями в нескольких зонах доступности, NAT-шлюз с таблицей маршрутизации, группа безопасности и бастион-хост с SSH-ключом в хранилище секретов.

> Инфраструктура опирается на [bootstrap](https://github.com/andrew-dibov/devops-bootstrap)

## Архитектура

### Слой 1 : Бэкенд и аутентификация

- **Terraform** : хранение удаленного состояния в S3-бакете
- **Доступ к состоянию** : статические ключи из Lockbox
- **Аутентификация** : API-ключ сервисного аккаунта из Lockbox

### Слой 2 : VPC и подсети

| Ресурс | Назначение | CIDR | Зона |
| :-- | :-- | :-- | :-- |
| `vpc--network` | Основная сеть | --- | --- |
| `vpc--subnet-public-a` | Публичная подсеть | `10.0.1.0/24` | `ru-central1-a` |
| `vpc--subnet-public-b` | Публичная подсеть | `10.0.2.0/24` | `ru-central1-b` |
| `vpc--subnet-private-a` | Приватная подсеть | `10.1.1.0/24` | `ru-central1-a` |
| `vpc--subnet-private-b` | Приватная подсеть | `10.1.2.0/24` | `ru-central1-b` |

- **NAT-шлюз** : интернет для приватных подсетей
- **Таблица маршрутизации** : маршрут `0.0.0.0/0` через NAT-шлюз

### Слой 3 : Бастион

VM с публичным адресом и соответствующей группой безопасности :

| Направление | Протокол | Порт | CIDR | Назначение |
| :-- | :-- | :-- | :-- | :-- |
| Ingress | `TCP` | `22` | `0.0.0.0/0` | SSH извне |
| Egress | `TCP` | `22` | `10.0.0.0/12` | SSH к приватным VM |
| Egress | `UDP` | `53` | `0.0.0.0/0` | DNS |
| Egress | `TCP` | `80` | `0.0.0.0/0` | HTTP |
| Egress | `TCP` | `443` | `0.0.0.0/0` | HTTPS |

## Технологии и навыки

| Категория | Технологии/Инструменты | Навыки |
| :-- | :-- | :-- |
| **Infrastructure as Code** | Terraform, Yandex Provider | Управление сетевыми ресурсами, управление секретами, параметризация через переменные окружения|
| **Yandex Cloud** | VPC, Public/Private Subnets, NAT Gateway, Route Tables, SEcurity Groups | Проектирование сети с изоляцией подсетей, настройка маршрутизации и правил безопасности |
| **Automation & Scripting** | Bash, jq, CLI | Извлечение секретов Lockbox, конфигурация бэкенда, инициализация окружения |
| **Security** | SSH, Lockbox, IAM-роли, Bastion | Безопасное хранение ключей, принцип минимальных привилегий |
| **Backend Management** | S3 Backend | Настройка удаленного хранения состояния |

## Развертывание

```bash
# скопировать и перейти
git clone git@github.com:andrew-dibov/devops-network.git && cd devops-network

# запустить скрипт инициализации
sudo chmod +x bash/* && ./bash/init.sh

# если планируешь работать дальше
source .env
```
