# Network

Создание сетевой инфраструктуры под рабочие нагрузки [проекта](https://github.com/andrew-dibov/devops). Создание виртуальной сети с публичными и приватными подсетями в нескольких зонах доступности под [high availability Kubernetes-кластером](https://github.com/andrew-dibov/devops-kubernetes), NAT-шлюза с таблицей маршрутизации для безопасного доступа в интернет из приватных подсетей и бастиона с соответствующей группой безопасности.

> Сетевая инфраструктура подразумевает готовность [bootstrap](https://github.com/andrew-dibov/devops-bootstrap)

## Архитектура

### Слой 1 : Инициализация : Bash

1. Создание .env-файла с авторизационными данными
2. Получение и экспорт JSON-ключа сервисного аккаунта
3. Инициализация удаленного бэкенда и развертывание инфраструктуры

### Слой 2 : Сетевая инфраструктура : Terraform

Виртуальная сеть включает в себя NAT-шлюз, таблицу маршрутизации и следующие подсети :

| Подсеть | Назначение | CIDR | Зона доступности |
| :-- | :-- | :-- | :-- |
| `vpc--subnet-public-a` | Публичная подсеть | `10.0.1.0/24` | `ru-central1-a` |
| `vpc--subnet-public-b` | Публичная подсеть | `10.0.2.0/24` | `ru-central1-b` |
| `vpc--subnet-private-a` | Приватная подсеть | `10.1.1.0/24` | `ru-central1-a` |
| `vpc--subnet-private-b` | Приватная подсеть | `10.1.2.0/24` | `ru-central1-b` |

### Слой 3 : Бастион : Terraform

Виртуальная машина с публичным адресом и группой безопасности со следующими правилами :

| Направление трафика | Протокол | Порт | CIDR | Назначение |
| :-- | :-- | :-- | :-- | :-- |
| **Ingress** | `TCP` | `22` | `0.0.0.0/0` | Входящий SSH |
| **Egress** | `TCP` | `22` | `10.0.0.0/12` | Исходящий SSH в приватные подсети |
| **Egress** | `UDP` | `53` | `0.0.0.0/0` | DNS |
| **Egress** | `TCP` | `80` | `0.0.0.0/0` | HTTP |
| **Egress** | `TCP` | `443` | `0.0.0.0/0` | HTTPS |

## Технологии и навыки

| Категория | Технологии/Инструменты | Навыки |
| :-- | :-- | :-- |
| **Infrastructure as Code, IaC** | Terraform | Управление сетевыми ресурсами, параметризация переменными окружения |
| **Yandex Cloud** | Virtual Private Cloud, Public/Private Subnets, NAT Gateway, Route Tables, Security Groups, Compute Instance | Проектирование сетевой инфраструктуры, изоляция подсетей, настройка маршрутизации и безопасности |
| **Automation & Scripting** | Bash | Автоматическая инициализация удаленного бэкенда |
| **Security** | Bastion, Lockbox | Безопасное хранение и передача учетных данных, доступ по принципу минимальных привилегий |

## Развертывание

```bash
# скопировать и перейти в репозиторий
git clone git@github.com:andrew-dibov/devops-network.git && cd devops-network

# запустить скрипт инициализации и экспортировать переменные окружения
sudo chmod +x bash/* && ./bash/init.sh
source .env
```
